- Strings are reproduced verbatim, including punctuation and capitalization. Whitespace inside a string has been collapsed to single spaces so each value fits one table row.
- The site has no i18n key system, so the **Key** column is a stable dot-path naming scheme; each section lists the DOM locator it maps to, so any edit can be traced back to the right element.
